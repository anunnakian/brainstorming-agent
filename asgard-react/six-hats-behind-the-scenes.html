The data flow

Agents don’t talk to each other. Each one reads keys from the shared AgenticScope and writes one key back. Odin is the goal: the planner works backwards from answer to find who has to run first. Badges show the order the run used.

02

How the planner picks the order

  1. init() turns every agent into edges of a graph: each @V argument → its outputKey. Heimdall is prompt → facts, Loki is facts, risk → creative.
  2. firstAction() runs an A* search (DependencyGraphSearch) from the keys already in the scope, {prompt}, to the goal, Odin’s answer. The result is one flat list of agents.
  3. nextAction() returns the next agent in that list until it is empty, then done(). One agent is in flight at a time.
// GoalOrientedPlanner
path = graph.search(scope.state().keySet(), goal);
// → [red-hat, white-hat, black-hat,
//    green-hat, yellow-hat, blue-hat]
return call(path.get(agentCursor++));

// nextAction
return agentCursor >= path.size()
    ? done()
    : call(path.get(agentCursor++));
